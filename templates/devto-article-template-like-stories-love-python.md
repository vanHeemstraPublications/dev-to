# Design Pattern Story Template

Use this prompt to explain any design pattern through storytelling and
practical examples.

------------------------------------------------------------------------

## Prompt

Explain the **{Design Pattern}** using the following structure:

### 1. One-line intent

A short, simple explanation of what the pattern does.

------------------------------------------------------------------------

### 2. Short story

A 1--2 sentence metaphorical story that captures the essence of the
pattern.

------------------------------------------------------------------------

### 3. Fictional match

A well-known movie, book, or story that reflects this pattern, with a
short explanation.

------------------------------------------------------------------------

### 4. Robert McKee story elements

-   **Protagonist**
-   **Desire (objective)**
-   **Antagonistic force**
-   **Central conflict**
-   **Turning point**
-   **Resolution**
-   **Controlling idea (theme)**

------------------------------------------------------------------------

### 5. Real-world practical implementations

A short bullet list of realistic software or system examples where this
pattern appears.

Examples: - Unique identifier generators - Logging systems - Plugin
systems - Payment methods - Event systems - Configuration managers

------------------------------------------------------------------------

### 6. Minimal Python example

A small, clear Python code snippet that demonstrates the pattern. Keep
it simple, readable, and practical.

------------------------------------------------------------------------

## Example usage

Prompt:

    Explain the Singleton design pattern using this template.

Prompt with theme:

    Explain the Strategy design pattern using this template,
    but set the story in a medieval kingdom.

Prompt for beginners:

    Explain the Observer design pattern using this template
    for beginner developers.
