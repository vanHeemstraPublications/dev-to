# 🎩 The Voice

Voice is character.

## Example

```bash
python3 voice/scripts/render_with_coqui_xtts.py \
  --text '"Please... stay."' \
  --emotion '"fragile"' \
  --output '"voice/output/candidates/please_stay.wav"'
```

## 🎩 Insight
Sound becomes personality when shaped with emotion.
