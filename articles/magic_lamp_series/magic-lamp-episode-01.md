# 🎩 Now You See Nothing… and Then a Lamp Speaks

Imagine a lamp that answers.

Not a gadget — a **presence**.

## The Trick

```
Lamp (Pi) → Mac Mini (Brain) → Voice → Back to Lamp
```

We move all intelligence offstage.

## Build Targets
- Body (Pi): mic, speaker, LEDs  
- Brain (Mac): HiveMind, STT, TTS, orchestration  
- Voice: Coqui XTTS  
- Timing: Ardour  

## 🎩 Insight
Hide complexity. Move it elsewhere. Let the audience see only life.
